CHECKPOINT - BLOG DE GAMES
Projeto AOP2 - Construção de Software para Web

Arquivos:
- index.html: página inicial
- hardware.html: página sobre hardware
- reviews.html: página sobre reviews
- novidades.html: página sobre novidades
- contatos.html: página de contatos
- style.css: estilos utilizados em todas as páginas

Para visualizar, abra o arquivo index.html no navegador.

Para publicar no GitHub Pages:
1. Crie um repositório público no GitHub.
2. Envie todos os arquivos para a raiz do repositório.
3. Acesse Settings > Pages.
4. Escolha Deploy from a branch, branch main e pasta /(root).
5. Salve e aguarde o link de publicação.

As imagens são carregadas da internet. O formulário de contato é demonstrativo.
